Here will some examples, part of them are copies of same windows examples, so you can check explanations there.


general info:

build:
```
./a.out --input-file=<path>
```

run - in /runtimes/0.3/lin
```
echo r <Nargs> <args> | ./a.out
```

or for normal shells:
```
"r <NARGS> <ARGS>" | ./a.out
```

(args - space separated numbers)
